## Companion Applications

- [Silo Franchises](https://github.com/Sietsevdm/silo-franchises) - A free, self-hosted companion to Silo for building and maintaining movie and TV franchise collections.
- [Siloscope](https://github.com/safetyp1/siloscope) - A mobile-friendly dashboard for monitoring Silo and InfiniDysk, viewing Silo and Plex playback, and managing media replacements with Sonarr and Radarr.
- [Siloscope (enhanced fork)]() - A monitoring and statistics dashboard for Silo and Plex in one place: live streams, server health, full playback history and Tautulli-style stats per user, with Silo and Plex accounts linked to the same person. Access is behind your Silo administrator sign-in, two-step included. Built mobile-first, it runs comfortably on a phone.

## 🌌 Related

This section includes software, guides and tools that are not *specifically* designed to work with Silo, but can be useful for tasks related to media management or to enhance Silo's functionality.
The links are maintained in [related.txt](related.txt), and GitHub descriptions are refreshed weekly through a pull request.

<!-- sort list:related -->
<!-- related-projects:start -->
- [FreeBSD Silo plugin catalog](https://github.com/mvanbaak/silo-plugins-freebsd) - This repository cross-compiles Silo's official plugin catalog for FreeBSD and republishes it in a catalog Silo can consume.
- [Seasonal episode lists](https://github.com/outragedpeanut/silo-seasonal-lists) - Seasonal episode lists for use with the Silo Seasonal Episodes plugin.
- [Siloquy](https://github.com/BEisem/siloquy) - Live Silo media server stats as Discord voice-channel counters.
